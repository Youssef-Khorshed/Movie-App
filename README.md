# Movie App Demo

A demo movie app showcasing the ability to log in using social media accounts and OTP, with support for both light and dark themes. The app includes a PHP Laravel backend, a mobile frontend built with Flutter, and uses the BLoC pattern for state management. The app also includes localization for multiple languages.
Features

    Social Login:
    Users can log in via popular social platforms (e.g., Google, Facebook).
    OTP Authentication: One-time password (OTP) authentication for secure login.
    Light & Dark Themes: Support for switching between light and dark modes.
    PHP Laravel Backend: The backend is built with PHP Laravel for handling APIs and authentication.
    Flutter Mobile App: The mobile app is developed using Flutter for cross-platform support.
    State Management (BLoC): Efficient state management using the BLoC pattern in Flutter.
    Localization: The app supports multiple languages for a global audience.
